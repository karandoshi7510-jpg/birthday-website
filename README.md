# AVU TURNS 18 ❤️ — Birthday Surprise Website

A bespoke, Pinterest-inspired romantic 18th birthday website designed for **AVU**.

---

## ✨ Features Included

1. **The Secret Surprise (Opening Screen)**
   - 3D animated blush pink envelope with rose gold wax seal.
   - Exact text: *"Hey AVU! Someone has prepared something special for you..."*
   - Interactive button: *"Open Your Birthday Surprise ❤️"*.
   - Wax seal break animation, flying hearts, and seamless musical fade-in.

2. **Welcome to 18**
   - Monumental animated number **18** in metallic rose-gold gradient with glowing aura.
   - Subtitle: *"A New Chapter, A Thousand Dreams & A Million Beautiful Moments."*
   - Welcoming message: *"Finally 18! Welcome to a beautiful new chapter of your life, AVU."*
   - Floating pastel balloons and interactive celebratory confetti cannon.

3. **Photo Memories (Aesthetic Scrapbook)**
   - 10 aesthetic polaroid photos with washi tape accents, dates, and sweet captions.
   - Fullscreen Lightbox Gallery with zoom, next/prev navigation, and sweet hug like counter.
   - Built-in **"Personalize / Swap Photos"** modal allowing direct image link paste or device photo upload (saved automatically to `localStorage`).

4. **18 Little Reasons**
   - 18 interactive luxury cards with deeply personal compliments and birthday wishes.
   - 3D card expansion with audio feedback.
   - Live discovery progress bar and celebratory fairy dust when all 18 reasons are unlocked.

5. **A Letter For AVU**
   - Vintage luxury envelope opening into an emotional parchment letter.
   - Real-time typewriter effect with skip and replay controls.

6. **Birthday Cake & 18 Candles**
   - Multi-tiered pastel cake with 18 individually animated candle flames.
   - Tap individual candles to blow them out (with smoke wisps) or tap *"Make a Wish & Blow All 18 Candles"*.
   - Confetti shower and star-blessing popup dialog.

7. **Cinematic Final Surprise**
   - Twilight sky lantern backdrop with the heartfelt tribute:
     > *"Happy 18th Birthday, AVU! ❤️*  
     > *May this new chapter bring you endless happiness, beautiful memories and everything your heart wishes for.*  
     > *Never stop being the wonderful person you are."*
   - Interactive *"Send Birthday Hug"* button with flying heart particles.
   - *"Reply via WhatsApp 💬"* button for instant messaging from mobile phones.
   - *"Replay Surprise"* button to restart the envelope experience.

8. **Audio & Sound Engine**
   - Built-in romantic acoustic music box melody powered by the Web Audio API (100% reliable offline, zero external file dependency).
   - Option to paste a custom MP3 link in the audio settings.
   - Tactile sound effects for candle blowing, confetti pops, card flips, and envelope opening.

---

## 🚀 Running the Project

```bash
# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

Open [http://localhost:5173/](http://localhost:5173/) on your desktop or mobile browser.
